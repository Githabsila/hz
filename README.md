# Поиск клиентов без сайта

Веб-приложение для поиска малого бизнеса, у которого нет сайта. Работает в браузере
на телефоне и на ПК, ставится на телефон как приложение. Сервер и API-ключи не нужны.

Два источника данных (переключаются в фильтрах):

- **2ГИС**: официальный Catalog API, самая полная база по России. Нужен ваш ключ API.
- **OpenStreetMap**: бесплатно и без ключа, но организаций меньше.

У каждой карточки есть кнопки «Яндекс», «2ГИС» и «Google», чтобы за один клик проверить
бизнес там.

## Ключ 2ГИС

1. Зарегистрируйтесь в кабинете https://platform.2gis.ru/ и создайте ключ для
   Places API (Catalog API). Сначала дают демо-ключ, потом нужен платный тариф.
2. В приложении откройте «Фильтры» → «Источник: 2ГИС» и вставьте ключ.
   Ключ хранится только в вашем браузере, на каждом устройстве его нужно вставить один раз.
3. «Страниц на запрос» задаёт глубину поиска. Каждая категория делает несколько
   поисковых запросов (например, «Красота» — парикмахерские, салоны, ногтевые студии…),
   и каждая страница результатов тратит один запрос из лимита ключа. На демо-ключе
   страница содержит до 10 организаций, на платном — до 50.

2ГИС ищет в круге радиусом до 40 км вокруг центра карты, а результаты за пределами
видимой области отбрасываются. Сетевыми считаются организации с 3 и более филиалами.

## Возможности

- Поиск по городу/району, по геолокации или по видимой области карты
- 16 категорий: салоны красоты, автосервисы, кафе, ремонт, стройка, медицина, ветеринария,
  фитнес, обучение, гостиницы, одежда, офисы и другие
- Фильтры: «только без сайта», «соцсеть — это не сайт» (бизнес, у которого есть только
  VK/Instagram, тоже считается кандидатом), «только с телефоном», «без сетевых брендов»
- Лиды с контактами показываются первыми
- Звонок одним касанием, WhatsApp и email с заранее заполненным текстом (шаблон можно менять)
- Мини-CRM: статусы «Новый / Написал / Интерес / Клиент / Отказ» и заметки
  (хранятся в браузере на этом устройстве)
- Экспорт в CSV для Excel и Google Таблиц

## Запуск

**Онлайн:** сайт публикуется на Netlify (https://poisk-klientov-bez-saita.netlify.app)
из ветки `master` этого репозитория. Откройте ссылку на телефоне и выберите
«Добавить на главный экран».

**Локально на ПК:** `python3 -m http.server 8000` в папке проекта, затем откройте
http://localhost:8000.

## Советы

- В большом городе ищите по районам: приблизьте карту, это быстрее и точнее.
- В OpenStreetMap есть не все организации, а поле «сайт» заполнено не всегда.
  Перед звонком проверяйте бизнес в Яндексе или 2ГИС.
