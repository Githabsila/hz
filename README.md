# Поиск клиентов без сайта

Веб-приложение для поиска малого бизнеса, у которого нет сайта. Работает в браузере
на телефоне и на ПК, ставится на телефон как приложение. Сервер и API-ключи не нужны.

Данные берутся из **OpenStreetMap** через бесплатный Overpass API. Это легальный открытый
источник: парсить Яндекс Карты, 2ГИС или Google Maps запрещают их правила. Вместо этого
у каждой карточки есть кнопки «Яндекс», «2ГИС» и «Google», чтобы за один клик проверить
бизнес там.

## Возможности

- Поиск по городу/району, по геолокации или по видимой области карты
- 16 категорий: салоны красоты, автосервисы, кафе, ремонт, стройка, медицина, ветеринария,
  фитнес, обучение, гостиницы, одежда, офисы и другие
- Фильтры: «только без сайта», «соцсеть — это не сайт» (бизнес, у которого есть только
  VK/Instagram, тоже считается кандидатом), «только с телефоном», «без сетевых брендов»
- Лиды с контактами показываются первыми
- Звонок одним касанием, WhatsApp и email с заранее заполненным текстом (шаблон можно менять)
- Мини-CRM: статусы «Новый / Написал / Интерес / Клиент / Отказ» и заметки
  (хранятся в браузере на этом устройстве)
- Экспорт в CSV для Excel и Google Таблиц

## Запуск

**Онлайн (рекомендуется):** включите GitHub Pages в репозитории:
Settings → Pages → Source: **GitHub Actions**. После следующего пуша приложение будет
доступно по адресу `https://<логин>.github.io/<репозиторий>/`. Откройте его на телефоне
и выберите «Добавить на главный экран».

**Локально на ПК:** `python3 -m http.server 8000` в папке проекта, затем откройте
http://localhost:8000.

## Советы

- В большом городе ищите по районам: приблизьте карту, это быстрее и точнее.
- В OpenStreetMap есть не все организации, а поле «сайт» заполнено не всегда.
  Перед звонком проверяйте бизнес в Яндексе или 2ГИС.
